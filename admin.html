Révocation forte

Retirer un code empêche toute nouvelle ouverture avec ce code. Mais un appareil déjà déverrouillé garde l'accès tant que la clé de chiffrement ne change pas. La révocation forte change la clé : tout le monde reçoit un nouveau code (affichés ci-dessous) et doit le ressaisir.
